# スライド4枚の骨子
1. 価値: Webサーバーのログには攻撃の跡が毎日残るが、人が全部読むのは無理。AIに読ませると「確実に攻撃」「WAFに反映しました」と勝手に断定・適用する危険がある。
2. 発想: AIだけのセキュリティチーム。立法Bot＝検知ルール W1〜W6、行政Bot＝ログ解析と対策案、司法Bot＝根拠のない検知・断定・自動適用を止める。適用を決めるのは人。Grok Bot 同士の三権分立。
3. デモ: ログ投入 → 検知（根拠の行番号・ルール番号付き）→ レポート v1 を check.sh が exit 1 で止める（NG 5件）→ v2 で PASS → 人が承認。
4. スケール: ルール TSV とログのパスを差し替えるだけ。`bin/new-goal.sh` で他のログ・他のチームにも。数字はデモ用ログで実測（検知件数・差し戻し回数・所要秒数）。
