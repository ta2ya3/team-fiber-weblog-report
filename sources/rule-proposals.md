## 0. 前提: 現行の判定方法（試算もこれに合わせた）

analyze.py を読んで確認した判定方法:

1. 正規表現ルールは**ログの1行全体（Referer・UA を含む）をデコードせずに** `re.search` する。README に書かれた仕様「URLデコード後に判定」とは違う
2. 検知件数は「1行×1ルール＝1件」。同じ行に W5 と W6 が両方当たれば2件
3. W4 は TSV の文面と関係なく**コードに直接書かれている**: `'"POST /login'` で前方一致し（`/login-action` も対象になる）、`" 401 "` の行を同一IPで**ログ全体**から数えて5回以上なら1件。**時間窓なし、ユーザー名の種類数も見ない**
4. TSV の type=`threshold` 行は W4 以外は無視される。W4 の名前も TSV ではなくコードの文字列が使われる

試算用の `trial/engine.py` はこの判定方法をそのまま作り直したもの。`verify_baseline.sh` で、本物の analyze.py と**現行ルールの出力が一致すること**、TSV だけで済む案を合成したときの出力も一致すること（62件）を確認した。
